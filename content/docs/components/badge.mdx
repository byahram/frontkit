## Playground

Basic Props는 기존 구현의 실제 속성이고, Design Preset은 `className` 조합입니다. Interactions는 향후 별도로 제공합니다.
설정을 바꾸거나 Preview를 조작하면 사용 예제와 Copy 내용도 갱신됩니다. Reset으로 기본 설정을 복원하세요.

## Preview / Code / Props

기존 new-york-v4의 Badge와 상태 표시 데모를 재사용합니다. 버튼이나 폼 입력이 아니라 상태와 분류를 표현하는 UI입니다.

<ComponentReference slug="badge">

기본 렌더링 요소는 `span`이며, 나머지 속성은 해당 요소에 전달합니다.

| Prop        | Type                                                              | Default   | 설명                                 |
| ----------- | ----------------------------------------------------------------- | --------- | ------------------------------------ |
| `variant`   | `default \| secondary \| destructive \| outline \| ghost \| link` | `default` | 상태와 강조 수준                     |
| `asChild`   | `boolean`                                                         | `false`   | Radix Slot으로 자식 요소에 속성 전달 |
| `children`  | `React.ReactNode`                                                 | 미지정    | 짧은 텍스트나 아이콘                 |
| `className` | `string`                                                          | 미지정    | 추가 스타일                          |

</ComponentReference>

## 사용 방법

```tsx
import { Badge } from "@/registry/new-york-v4/ui/badge"

export function StatusBadges() {
  return (
    <div className="flex flex-wrap gap-2">
      <Badge variant="secondary">진행 중</Badge>
      <Badge variant="outline">검토 대기</Badge>
    </div>
  )
}
```

색상만으로 상태를 구분하지 말고 의미 있는 텍스트를 함께 제공하세요.
클릭 동작이 필요하면 기본 `span`에 이벤트를 붙이기보다 적절한 링크·버튼 요소를 선택합니다.

## Basic Variants / 상태 및 디자인

Playground에서 기존 6개 Variant를 비교할 수 있습니다. basic / square / soft는 className으로 조합한 디자인 예제입니다. Variant API는 변경하지 않습니다.
